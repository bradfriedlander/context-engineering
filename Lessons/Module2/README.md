# **Module 2: Advanced Prompting Techniques**

This module moves beyond the basics into the craft of advanced prompt engineering. We will dissect the components of a sophisticated prompt and learn a variety of powerful techniques, from Chain-of-Thought reasoning to Few-Shot examples, that enable us to elicit more accurate and complex behavior from LLMs.
