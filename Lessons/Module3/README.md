# **Module 3: Retrieval-Augmented Generation (RAG)**

This module introduces the most important architectural pattern in modern AI: Retrieval-Augmented Generation (RAG). We will explore how to connect LLMs to external knowledge bases to create applications that are grounded in factual, up-to-date information, effectively mitigating hallucination.
